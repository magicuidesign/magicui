}

### Custom Card (`children`)

Pass a render function to customize card markup while preserving 3D slot animations and SVG bridges:

```tsx showLineNumbers
<BridgedCarousel items={items} cardWidth={680} cardHeight={440}>
  {(item, { active, select }) => (
    <div
      onClick={select}
      className={`relative h-full w-full overflow-hidden p-6 transition-all ${
        active
          ? "bg-card text-card-foreground shadow-xl"
          : "bg-muted/40 cursor-pointer opacity-70 hover:opacity-100"
      }`}
    >
      {item.image && (
        <img
          src={item.image.src}
          alt={item.image.alt}
          className="absolute inset-0 h-full w-full object-cover opacity-30"
        />
      )}
      <div className="relative z-10 flex h-full flex-col justify-end">
        <h3 className="text-xl font-semibold">{item.title}</h3>
        {active && (
          <p className="text-muted-foreground mt-2 text-sm">
            {item.description}
          </p>
        )}
      </div>
    </div>
  )}
</BridgedCarousel>
```

## Props

| Prop             | Type                         | Default | Description                                                               |
| ---------------- | ---------------------------- | ------- | ------------------------------------------------------------------------- |
| `items`          | `BridgedCarouselItem[]`      | `[]`    | Array of card data items to display.                                      |
| `activeIndex`    | `number`                     | `-`     | Controlled active slide index.                                            |
| `defaultIndex`   | `number`                     | `0`     | Initial active slide index in uncontrolled mode.                          |
| `onSlideChange`  | `(index: number) => void`    | `-`     | Callback fired when the active slide changes.                             |
| `autoplay`       | `number \| false`            | `3000`  | Rotation interval in milliseconds, or `false` to disable.                 |
| `cardWidth`      | `number \| string`           | `762`   | Width of the active center card.                                          |
| `cardHeight`     | `number \| string`           | `513`   | Height of the active center card and stage.                               |
| `loop`           | `boolean`                    | `true`  | Whether navigation wraps around cyclically.                               |
| `showConnectors` | `boolean`                    | `true`  | Whether to render dynamic SVG bridges between adjacent cards.             |
| `showControls`   | `boolean`                    | `true`  | Whether to display the navigation arrows and progress bar.                |
| `children`       | `(item, state) => ReactNode` | `-`     | Custom card render function receiving `(item, { active, slot, select })`. |
| `className`      | `string`                     | `-`     | Additional class names applied to the container.                          |
