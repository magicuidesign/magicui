## Patterns

Pass any of these ids to `pattern`. The first five are light patterns in your `color`. The other twelve ship with their own colors, Bayer matrix and dot size. Pass `palette` to recolor one.

<ComponentPreview name="dither-patterns-demo" />

## Props

| Prop          | Type                 | Default          | Description                                                                                                       |
| ------------- | -------------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| `pattern`     | `string`             | `"horizon"`      | A light pattern (`horizon`, `glow`, `aurora`, `waves`, `clouds`) or a palette pattern (see [Patterns](#patterns)) |
| `src`         | `string`             | `-`              | Image or video URL to dither instead. Remote files must allow CORS                                                |
| `color`       | `string \| string[]` | `"currentColor"` | A CSS color, or a `[low, mid, high]` ramp from dim to bright dots. Palette patterns ignore it                     |
| `palette`     | `string[]`           | `-`              | Override the colors of a palette pattern, from darkest to brightest. Any CSS color works                          |
| `matrix`      | `2 \| 4 \| 8`        | `8`              | Size of the Bayer matrix. Larger matrices give finer, smoother steps. Palette patterns pick their own             |
| `dotSize`     | `number`             | `1`              | Size of one dot in CSS pixels. Palette patterns pick their own size unless you set it                             |
| `intensity`   | `number`             | `0.75`           | Brightness of the field                                                                                           |
| `speed`       | `number`             | `1`              | Animation speed. `0` holds a still frame                                                                          |
| `fps`         | `number`             | `30`             | Maximum frames per second                                                                                         |
| `interactive` | `boolean`            | `false`          | Brighten the dots under the pointer                                                                               |
