## Usage

```tsx showLineNumbers
import { InkReveal } from "@/components/ui/ink-reveal"
```

```tsx showLineNumbers
<InkReveal className="rounded-xl border">
  <img src="/dashboard.png" alt="The revenue dashboard" />
</InkReveal>
```

The reveal plays once, when the frame scrolls into view. Change its `key` to replay it.

The cover is a solid sheet of `background`, so set `background` to the surface behind the frame. Put `rounded-*`, `border` and `shadow-*` on `InkReveal` itself, since it clips its children.

## Props

`InkReveal` accepts every `div` prop.

| Prop         | Type     | Default                     | Description                                      |
| ------------ | -------- | --------------------------- | ------------------------------------------------ |
| `duration`   | `number` | `1.5`                       | Length of the reveal, in seconds.                |
| `delay`      | `number` | `0`                         | Seconds to wait after the frame comes into view. |
| `color`      | `string` | `"var(--muted-foreground)"` | Color of the ink at the stain's edge.            |
| `background` | `string` | `"var(--background)"`       | Color of the cover.                              |
