## Usage

```tsx showLineNumbers
import { PluckedRule } from "@/components/ui/plucked-rule"
```

```tsx showLineNumbers
<PluckedRule className="my-10" />
```

Leave up to `amplitude` pixels clear above and below the rule, outside any
`overflow-hidden` parent, and set its color with `colorFrom` and `colorTo`
rather than a `bg-*` class.

## Props

| Prop        | Type     | Default               | Description                                                     |
| ----------- | -------- | --------------------- | --------------------------------------------------------------- |
| `colorFrom` | `string` | `"var(--border)"`     | Color of the line, where the highlight gradient starts          |
| `colorTo`   | `string` | `"var(--foreground)"` | Color at the pluck point, where the highlight gradient ends     |
| `size`      | `number` | `1`                   | Thickness of the line in pixels                                 |
| `amplitude` | `number` | `24`                  | Largest bend in pixels, capped at 6% of the line's width        |
| `duration`  | `number` | `1.5`                 | Seconds for a ring from the largest bend to settle              |
| `frequency` | `number` | `5`                   | Vibrations per second. Higher reads as tighter                  |
| `delay`     | `number` | `0.4`                 | Seconds after first entering view before the rule plucks itself |
