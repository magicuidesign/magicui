## Usage

```tsx showLineNumbers
import { KeycapSequence } from "@/components/ui/keycap-sequence"
```

```tsx showLineNumbers
<KeycapSequence keys={["⌘", "⇧", "P"]} />
```

Hovering replays the keys. The component only displays the shortcut; it does
not listen for it.

## Props

| Prop          | Type       | Default      | Description                                                        |
| ------------- | ---------- | ------------ | ------------------------------------------------------------------ |
| `keys`        | `string[]` | `["⌘", "K"]` | Labels in pressing order, modifiers first                          |
| `size`        | `number`   | `24`         | Key height in pixels                                               |
| `duration`    | `number`   | `1.1`        | Seconds for one press and release                                  |
| `delay`       | `number`   | `0.25`       | Seconds to wait after the keys scroll into view                    |
| `repeatDelay` | `number`   | `1.8`        | Seconds to pause after a play before the next one starts           |
| `aria-label`  | `string`   | `-`          | Screen reader text. Defaults to the key names, such as "Command K" |
