## Usage

```tsx showLineNumbers
import { ScrollTrace } from "@/components/ui/scroll-trace"
```

```tsx showLineNumbers
<ScrollTrace className="space-y-16">
  <article className="group">
    <h3 className="text-muted-foreground group-data-reached:text-foreground">
      Connect a repository
    </h3>
    <p>Dockyard detects your framework and build settings.</p>
  </article>
  <article className="group">
    <h3 className="text-muted-foreground group-data-reached:text-foreground">
      Ship a release
    </h3>
    <p>Promote a healthy preview when your team is ready.</p>
  </article>
</ScrollTrace>
```

The line follows the page or the nearest scrolling container.

Each direct child is a step, with a marker beside its first line of text. A step gets `data-reached` once the line passes it, so `group-data-reached:` variants can highlight it. Space the steps with `space-y-*` and widen the gutter the line runs in with `ps-*` (default `ps-14`). The line layer is the root's first child, and `*:`, `odd:`, `even:` and `nth-*` variants count it, so use `first-of-type:` rather than `first:` to target the first step.

## Props

| Prop        | Type     | Default     | Description                                                                                        |
| ----------- | -------- | ----------- | -------------------------------------------------------------------------------------------------- |
| `colorFrom` | `string` | `"#ffaa40"` | Gradient color at the first step                                                                   |
| `colorTo`   | `string` | `"#9c40ff"` | Gradient color at the last step, and the color of the moving tip                                   |
| `curvature` | `number` | `14`        | Sideways bow between markers in pixels, capped to fit the `ps-*` gutter. `0` draws a straight line |
| `duration`  | `number` | `0.9`       | Seconds the line takes to draw in the first time the list scrolls into view                        |
