## Usage

Import the component:

```tsx
import { SlideSwapButton } from "@/components/ui/slide-swap-button"
```

Use the component:

```tsx
<SlideSwapButton>Get Started</SlideSwapButton>
```

## Custom Icon

Pass a custom React node through the `icon` prop to replace the default arrow icon.

```tsx
import { ArrowUpRight } from "lucide-react"

import { SlideSwapButton } from "@/components/ui/slide-swap-button"

export default function Demo() {
  return <SlideSwapButton icon={<ArrowUpRight />}>Explore More</SlideSwapButton>
}
```

## Link Usage

Provide an `href` to render the component as a native anchor element instead of a button.

```tsx
<SlideSwapButton href="/docs">Explore Documentation</SlideSwapButton>
```

## Customization

Customize the button's dimensions, colors, and animation timing using CSS variables through the `style` prop.

```tsx
<SlideSwapButton
  style={{
    "--swap-btn-height": "56px",
    "--swap-btn-radius": "12px",
    "--swap-btn-font-size": "12px",
    "--swap-btn-icon-size": "32px",
    "--swap-btn-accent": "#2563eb",
    "--swap-btn-move-duration": "0.6s",
    "--swap-btn-fill-duration": "0.5s",
  }}
>
  Customize Button
</SlideSwapButton>
```

## Props

| Prop        | Type                              | Default        | Description                                               |
| ----------- | --------------------------------- | -------------- | --------------------------------------------------------- |
| `children`  | `ReactNode`                       | Required       | Content displayed as the button label.                    |
| `icon`      | `ReactNode`                       | Default arrow  | Custom icon displayed inside the circular icon container. |
| `href`      | `string`                          | `undefined`    | Renders an anchor element when provided.                  |
| `className` | `string`                          | `undefined`    | Additional CSS classes for customization.                 |
| `style`     | `SwapButtonStyle`                 | Default styles | Custom CSS properties and inline styles.                  |
| `type`      | `"button" \| "submit" \| "reset"` | `"button"`     | Native button type.                                       |

All standard HTML button and anchor attributes are supported by their respective variants.
