## Usage

```tsx showLineNumbers
import { ExpandingFrame } from "@/components/ui/expanding-frame"
```

```tsx showLineNumbers
<ExpandingFrame>
  <img src="/dashboard.png" alt="Product dashboard" />
</ExpandingFrame>
```

- Pad text inside the frame with `px-[calc(var(--frame-inset)+1.5rem)]` so it reads before the frame opens.
- Use `overflow-x-clip` on `body` and page wrappers, never `overflow-hidden` or `overflow-x-hidden`; either stops the frame from pinning.
- Under a fixed header, add `scroll-pt-*` to `html` so the frame pins below it.
- Inside your own scroller, give it `@container-size` so the server HTML matches the final frame size.
- For a landscape screenshot, set `frameClassName="aspect-video"` (or a responsive ratio); `object-*` on the child controls cropping.

## Props

| Prop             | Type        | Default | Description                                                                                                                                   |
| ---------------- | ----------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `children`       | `ReactNode` | `-`     | An image, video or product UI. It fills the frame                                                                                             |
| `travel`         | `number`    | `460`   | Pixels of scroll the frame stays pinned while it opens. `0` turns off the scroll opening                                                      |
| `inset`          | `number`    | `9`     | Percent of the width hidden on each side at rest, from `0` to `30`. Frames narrower than `40rem` use 55% of it                                |
| `borderRadius`   | `number`    | `32`    | Corner radius in pixels at rest, squaring off as the frame opens. Add a `rounded-*` class to `frameClassName` to keep round corners when open |
| `scale`          | `number`    | `1.13`  | Zoom on the content at rest, easing to `1` as the frame opens. `1` turns the zoom off                                                         |
| `duration`       | `number`    | `1.15`  | Seconds the frame takes to widen when it first comes into view                                                                                |
| `delay`          | `number`    | `0`     | Seconds to wait before it widens                                                                                                              |
| `frameClassName` | `string`    | `""`    | Classes for the frame. It fills the visible height by default; an `aspect-*` or `h-*` class replaces that                                     |
| `className`      | `string`    | `-`     | Classes for the outer wrapper                                                                                                                 |
