```tsx showLineNumbers

```

## Props

| Prop            | Type                      | Default              | Description                                               |
| --------------- | ------------------------- | -------------------- | --------------------------------------------------------- |
| `placeholder`   | `string`                  | `"Enter your em@il"` | Placeholder text shown in the input.                      |
| `type`          | `HTMLInputTypeAttribute`  | `"email"`            | The HTML input type.                                      |
| `name`          | `string`                  | `"email"`            | The name attribute for the input.                         |
| `label`         | `string`                  | `"Email"`            | Accessible label announced by screen readers.             |
| `onValueSubmit` | `(value: string) => void` | `-`                  | Called with the trimmed value when the form is submitted. |
| `className`     | `string`                  | `-`                  | Additional class names for the form element.              |

Type something, then press Enter or click the arrow. The glyph blows apart into dust. The icon morphs from an arrow into a pen while you type.
